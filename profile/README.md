# upstream-wontfix

Unofficial clients, SDKs and tools for things whose official software is missing,
closed, clunky or abandoned: routers, gadgets, apps and services too niche for
anyone else to bother with.

The vendor won't fix it, so these do.

## What to expect

- **Niche by design.** Each project scratches one specific itch, usually for one
  device or service.
- **AI-assisted.** Most code here was written with an AI coding assistant and
  tested against real hardware or services by a human. It works for the
  configurations listed in each README, and maybe nothing else.
- **Unofficial.** Nothing here is affiliated with or endorsed by the vendors whose
  products it talks to. Trademarks belong to their owners.

## Before you use anything here

All projects are provided **as is, with no warranty and no liability**. Read the
code before you run it, check each repo's license and disclaimer, and only use
these tools on devices and accounts you own or are authorised to use.

Issues and pull requests are welcome, but support is best-effort.
